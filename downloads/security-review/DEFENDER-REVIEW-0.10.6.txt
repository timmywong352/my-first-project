Application purpose
An unpacked Manifest V3 browser extension for LiveChat customer support. It
reads permitted chat/report pages, retrieves user-configured knowledge, and
prepares editable customer replies. It does not automatically send replies.
The manifest requests storage and scripting permissions for specified sites.

Reviewed file roles
archive-core.js: local conversation preparation, masking, topic classification,
statistics and CSV export; no network or system-command execution in this file.
withdrawal-rules.js: deterministic status parsing, multilingual reply templates,
report matching, freshness and pagination guards; no network or system-command
execution in this file.
background.js: extension message routing, local storage/index operations,
LiveChat/Groq/Google requests, and packaged report scripts injected into the
authorized backend pages. LiveChat/Groq credentials are read from the user's
local extension settings; no actual credentials are embedded in this report.

Comparison with 0.10.5
The ZIP contains the same 46 file names, with no added executable files and no
