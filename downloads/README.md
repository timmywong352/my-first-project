# Smart Reply 0.8.7

Download `SMART-Reply-0.8.7.zip`, extract it, and use the contained `Smart Reply` folder as your unpacked browser extension.

SHA-256:

This release changes Live Copilot to the requested draft-only workflow. It prepares the expected reply directly in the empty LiveChat message box; the agent checks or edits it and presses Enter manually. Copilot never sends a message.
