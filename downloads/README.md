# Smart Reply 0.9.3

Download `SMART-Reply-0.9.3.zip`, extract it, and use the contained `Smart Reply` folder as your unpacked browser extension.

SHA-256:

```text
ec9ebe881761926ac4bec851f9bf5100c43b7b5a00d3d420818c09f466ef5cd0
```

This release makes the whole Smart Reply panel easier to read, with 15px main text, clearer 13–14px controls and result fields, and larger headings. The compact responsive layout and all 0.9.2 per-chat, read-only, empty-composer, and manual-send safeguards remain unchanged.
