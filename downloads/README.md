# Smart Reply 0.10.1

Download `SMART-Reply-0.10.1.zip`, extract it, and use the contained `Smart Reply` folder as your unpacked browser extension.

SHA-256:

```text
cadd8c7f424bc55ed5a0eaf806118f6bcd9333ebcdd5c31d1718518b6f432060
```

This release fixes Auto language for mixed Malay shorthand and respects a Bahasa Melayu pre-chat selection when only weak shared terms such as `I` and `withdraw` appear. It also maps the explicit backend wording `Unfinish Turnover, Still Need RM-271 Be Closed` to RM271 still required, prepares the approved sentence in the detected language, and makes the highlighted result insert that full sentence instead of the waiting reply. Ambiguous standalone negative amounts remain blocked, all composer safeguards remain active, and nothing sends automatically.
