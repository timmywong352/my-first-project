# Smart Reply 0.10.0

Download `SMART-Reply-0.10.0.zip`, extract it, and use the contained `Smart Reply` folder as your unpacked browser extension.

SHA-256:

```text

```

This release adds a Dynamic Decision Copilot. Every common-question result is labelled Safe draft, Review, or Operator with a reason; operator handoffs and Quick Check escalations receive stable per-enquiry SR case IDs. Good, Needed edit, and Wrong/operator feedback feeds a local quality summary without storing customer messages, generated reply text, or backend records. Global approved-topic search and all existing composer protections remain in place, and nothing sends automatically.
