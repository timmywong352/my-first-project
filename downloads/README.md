# Smart Reply 0.9.4

Download `SMART-Reply-0.9.4.zip`, extract it, and use the contained `Smart Reply` folder as your unpacked browser extension.

This release adds verified full-sentence recommendations after Deposit, Promotion, and Withdrawal Quick Checks. Successful deposits include amount and backend confirmation time; explicitly credited bonuses include code and backend confirmation time; Payment closed recommends resubmission; and strictly verified positive turnover can produce the remaining RM amount. Uncertain results stay waiting/operator-only, and nothing is sent automatically.
