# Smart Reply 0.9.1

Download `SMART-Reply-0.9.1.zip`, extract it, and use the contained `Smart Reply` folder as your unpacked browser extension.

SHA-256:

```text
6ea10b4b5990c1f33430972b0669d5ec26fa4e98ebb5646bcf2fe40917c90b7f
```

This release makes simple game-access complaints answer immediately with a safe detected-language clarification before archive or AI lookup. It asks which game failed and requests the error or screenshot without guessing a cause. The fast resumable archive index and no-reset migration remain included, and all output stays draft-only.
