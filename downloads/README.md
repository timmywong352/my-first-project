# Smart Reply 0.9.9

Download `SMART-Reply-0.9.9.zip`, extract it, and use the contained `Smart Reply` folder as your unpacked browser extension.

SHA-256:

```text
3c9522b0822631bb095038f310f3b6bb3bb3084cd522cda77ffe5e92f88d1285
```

This release removes the withdrawal-reference confirmation checkbox. Clicking the highlighted withdrawal result now places its approved, editable sentence directly into the empty LiveChat composer; nothing sends automatically. The Withdrawal result adds Promotion code, Promotion confirm time, Promotion turnover, and Promotion status, while removing Requested time and Reference. A Withdrawal search reads all four required reports once and caches the matching Deposit and Promotion results inside that chat. Standalone Deposit and Promotion checks still retrieve only their own required reports.
