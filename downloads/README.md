# Smart Reply 0.9.2

Download `SMART-Reply-0.9.2.zip`, extract it, and use the contained `Smart Reply` folder as your unpacked browser extension.

SHA-256:

```text
4641a5e6880d45cc02c8e80b0c93ecacd58728d2af1e060f109a0f7aa6ed4da6
```

This release adds the simple per-chat Quick Check workspace for Deposit, Promotion, and Withdrawal. It detects the chat username, supports correction, Auto/English/Malay/Chinese, Today/Last 7 days, and isolates every result and draft by exact LiveChat chat ID. Backend access remains read-only, replies only enter an empty composer, and nothing is sent automatically.
