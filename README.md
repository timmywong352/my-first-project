# Smart Reply 0.10.0

Public download branch for Smart Reply 0.10.0.

Download [SMART-Reply-0.10.0.zip](downloads/SMART-Reply-0.10.0.zip), extract it, and use the contained `Smart Reply` folder as your unpacked browser extension.

To test before updating, download [SMART-Reply-0.10.0-TEST.zip](downloads/SMART-Reply-0.10.0-TEST.zip). Temporarily disable the current extension, load the separate `Smart Reply TEST` folder unpacked, and follow its included instructions. Do not enable both copies together.

The TEST ZIP SHA-256 is `350e764f521097dddb78b8a42dbb4069966166ba6438db4d311cea80bc082606`.
